Qué pasa cuando pulsas Ejecutar

No es una animación: cada paso corresponde a algo real que puedes revisar en el repositorio.

  1. Disparo

    Esta página pide a un servicio intermedio que lance el workflow, sin exponer ningún token.

  2. Ejecución

    GitHub Actions levanta el entorno y corre la suite que elegiste.

  3. Seguimiento

    La página consulta el estado de cada paso y lo muestra mientras avanza.

  4. Reporte

    Al terminar, publica el reporte con evidencias y te enlaza la ejecución.
